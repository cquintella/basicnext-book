# Basic Next Book

This edition of the tutorial teaches Basic Next **0.6.10**. Every complete example in the book is checked against the `bni` 0.6.10 release binary by `scripts/check-examples.sh`, a shell script that needs only `bash`, `awk`, and `bni`:

```sh
BNI=/path/to/bni BN_STDLIB=/path/to/BasicNext/modules/bn scripts/check-examples.sh
```

The book is in four parts — getting started, the procedural language, objects and memory, and programs in the real world — followed by reference appendices. Each chapter uses only what the chapters before it have taught.

Official website: [http://basicnext.org](http://basicnext.org)

Start at [`en/toc.md`](en/toc.md).
